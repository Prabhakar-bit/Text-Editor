# Text-Editor
Python Text Editor using Tkinter

A simple desktop text editor built with Python and Tkinter that allows users to create, open, edit, and save text files through an intuitive graphical user interface. This project demonstrates the fundamentals of GUI development, file handling, and event-driven programming in Python.

✨ Features
📝 Create a new text document
📂 Open existing .txt files
💾 Save text files
🖥️ User-friendly GUI using Tkinter
📋 Menu bar with New, Open, Save, and Exit options
🛠️ Tech Stack
Python
Tkinter
File Handling
